# Smart CivicFix — Bug Hunters

A simple open-source front-end prototype for the Bharat Hack for Social Cause concept.

## Features
- Submit a civic issue with title, category, location, and description
- Search reports and filter by status
- Update report status on the dashboard
- Basic duplicate-report warning for matching title and location
- Responsive layout for laptop and mobile screens
- Sample reports clearly identified as demo data

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser. No build tools or dependencies are required.

## Important limitations
This is a front-end demonstration only. Reports and status changes live in page memory and reset on refresh. There is no backend, login, real AI classification, map integration, image storage, or connection to government departments. Do not present demo records as real complaints.

## Suggested next steps
- Add a backend API and database.
- Add secure authentication and role-based access.
- Add real image storage and location mapping.
- Test accessibility, privacy, and duplicate detection.
- Add AI classification only after validating data and safeguards.
